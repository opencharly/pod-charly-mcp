# pod-charly-mcp

The `charly-mcp` candy of [opencharly/charly](https://github.com/opencharly/charly), as a standalone
repo — the candy de-submodule cutover, kind-prefixed naming. `pod-` because the candy declares a
`service:` and `port: 18765`.

It declares **1 `skill:` entity**, generated into
[opencharly/marketplace](https://github.com/opencharly/marketplace) by that repo's workflow. Edit
the `skill:` entity in `charly.yml`; never the generated `SKILL.md`.
